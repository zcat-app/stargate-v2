# Extension illustrations

These images illustrate the Firefox 0.8.9 interface. Theme choices change the
appearance, not the routing behavior.

- `connected-*.png` render the extension UI with synthetic settings state and
  the reserved example address `https://gate.example.org:9443`. Each image is
  visibly labeled as an illustrative demo with no live connection. No server
  was contacted and no access code or device credential is represented.
- `setup-form.png`, `appearance-controls.png` and `ipfs-tool.png` show the signed
  extension in an unpaired browser. Form fields are empty. The IPFS gateway is
  the extension's public default; no content has been opened.

Images illustrate controls, not current network availability or a completed
routing test. Project UI artwork and screenshots use Apache-2.0.
