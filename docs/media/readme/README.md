# README artwork and screenshots

The banner uses Stargate portal and Observatory planet artwork from the extension,
with outlined DejaVu Sans lettering. No external font, script or animation is
loaded. The lit portal is branding, not a connection-status indicator.

The Mozilla Add-ons badge is original project artwork: outlined DejaVu Sans
lettering beside an abstract swirl in Firefox gradient colors. "Firefox" and
"Mozilla Add-ons" are Mozilla trademarks; the badge only links to the store
listing and implies no endorsement.

The three `*-popup.png` screenshots show the signed Firefox 0.8.9 extension
before pairing. They use empty fields and example placeholders. The older
`stargate-settings.png`, `onboarding.png` and `quick-start-guide.png` captures
show 0.8.8 in Brave 1.98.60 before pairing. They illustrate controls, not network
access or a completed accessibility audit.

The README also uses [shared extension illustrations](../extension/README.md),
including captioned connected-state illustrations with a reserved example address.

Project artwork and UI screenshots use Apache-2.0. Font-derived outlines retain
the [DejaVu/Bitstream notice](DejaVu-LICENSE.txt); no font file is bundled.
